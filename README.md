VitSecureDrive
-Developed a secure cloud file storage system that detects malicious uploads and encrypts clean files before cloud storage, ensuring confidentiality and safe file sharing.
-Integrated ClamAV and heuristic analysis to detect and block suspicious or malware-infected files before upload.
-Implemented hybrid AES-GCM and RSA encryption to secure file contents and protect encryption keys.
-Built a Flask-based web application with Google Drive API integration for secure file upload, retrieval, and decryption.
